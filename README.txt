SELBy JOWSEY PHOTOGRAPHY — WEBSITE STARTER

This is an original photography portfolio/archive website inspired by the clean, image-first structure of the BWmedia archive.

FILES
- index.html
- style.css
- script.js
- images/ (put your photos here)

QUICK EDITS
1. Replace the grey placeholder blocks with your photos.
2. Replace the placeholder email address in index.html with your real business email.
3. Add your Instagram URL.
4. Change each gallery card's href="#" to the link for that gallery.

To use a local image, replace:
<div class="card-image placeholder"><span>HOCKEY PHOTO</span></div>
with:
<div class="card-image"><img src="images/hockey.jpg" alt="Hockey photography"></div>

Then add this to style.css:
.card-image img,.hero-image img,.about-photo img{width:100%;height:100%;object-fit:cover;display:block}

You can host this on Netlify, Cloudflare Pages, GitHub Pages, Squarespace (with adaptation), or your own web host.
